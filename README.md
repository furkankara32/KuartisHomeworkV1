# Kuartis Embedded Software Homework

Embedded software and ROS2 integration project developed for the  
**Kuartis Hardware and Embedded Systems Group – Embedded System Pipeline Homework**.

## Project Overview

This project uses an **STM32F767ZI** based embedded system together with a **BNO085 IMU**.

The embedded firmware is designed to:

- Communicate with the BNO085 over SPI.
- Use interrupt- and DMA-based sensor communication.
- Read the BNO085 Rotation Vector output.
- Convert quaternion data into Euler angles.
- Calculate heading in degrees.
- Generate an NMEA 0183 heading message.
- Transmit NMEA data to a PC over UART using DMA.
- Use a TX ring buffer for asynchronous serial transmission.
- Run the application using FreeRTOS.
- Measure timing and execution performance with a 1 us resolution hardware timer.

A ROS2 driver will later receive the embedded output and publish the corresponding ROS2 sensor data.

## Peripheral Configuration

### BNO085 - SPI2

| Signal | STM32 Pin |
|---|---|
| SCK | PB13 |
| MISO | PC2 |
| MOSI | PB15 |
| CS | PB12 |
| WAKE | PA8 |
| INT | PC8 |
| RESET | PC9 |

SPI configuration:

- Master mode
- Full duplex
- 8-bit data
- MSB first
- SPI Mode 3
- DMA RX/TX

### Debug / NMEA UART

USART3:

- TX: PD8
- RX: PD9
- Baud rate: 115200
- Format: 8N1
- TX: DMA
- Software TX ring buffer

### Performance Timer

TIM2 is configured as a free-running 32-bit timer.

Target resolution:

```text
1 timer count = 1 us
```

This timer will be used to measure:

- Sensor update period
- Minimum period
- Maximum period
- Average period
- Jitter
- Processing latency

## FreeRTOS

Initial task architecture:

| Task | Responsibility |
|---|---|
| Bno085Task | Sensor processing and heading calculation |
| NmeaTask | NMEA 0183 message generation |
| UartTxTask | UART TX queue and ring-buffer transmission |

FreeRTOS queues will be created manually in the application code rather than generated by STM32CubeMX.

---

## Heading Calculation

The BNO085 Rotation Vector output provides fused orientation data as a quaternion.

The quaternion will be converted to Euler angles and yaw will be converted to a heading in the range:

```text
0 degrees <= heading < 360 degrees
```

No additional Kalman filter is planned for the initial implementation.

---

## NMEA 0183

The initial implementation will use an NMEA magnetic heading sentence.

Example:

```text
$HCHDM,123.4,M*CS
```

The checksum will be generated according to the NMEA 0183 XOR checksum method.

## ROS2 Integration

The ROS2 side is planned as a C++ lifecycle driver.

Planned functionality:

- `rclcpp_lifecycle::LifecycleNode`
- Serial port communication
- NMEA parsing
- `sensor_msgs/msg/Imu` publishing
- `base_link -> imu_link` TF2 transform
- `/diagnostics` publishing
- Output-frequency monitoring

Lifecycle states:

```text
Unconfigured
     |
     v
Inactive
     |
     v
Active
```
